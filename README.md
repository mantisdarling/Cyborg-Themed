# TECHFEST IIT BOMBAY CYBORG EXHIBITION

Manga monochrome cyborg landing page engineered for the Techfest IIT Bombay Cybernetics and Biomechatronics showcase.

## System Architecture

* **Visual Aesthetic**: Pure high contrast manga monochrome (stark pitch black and white with screentone textures).
* **Robotic Ferrofluid Engine**: Real time 60 FPS viscous magnetic fluid simulation with cursor interaction and magnetic flux lines.
* **Animated Techfest Insignia**: Vector Techfest TF monogram insignia with continuous stroke draw and hovering animations.
* **Biomechanical Diagnostic Console**: Interactive 4 state anatomical inspection stage (Titanium Skeleton, Carbon Musculature, Neural Bus Intercept, Synthetic Dermal Shield).
* **Live Action Potential Oscilloscope**: Real time biophysical nerve wave generator using canvas rendering.
* **Scientific Foundations**: Formulated upon the cybernetics principles of Norbert Wiener, the 1960 cyborg concept of Manfred Clynes and Nathan Kline, and the neural biomechatronics research of Hugh Herr.
* **Mechanical Sound Engine**: Web Audio API oscillator synthesis generating tactile metallic feedback.

## Setup and Development

npm install
